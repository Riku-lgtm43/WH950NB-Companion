# WH950NB Companion v0.3.21 — Beta 1

**Tag:** `v0.3.21-beta.1` · **Pre-release**

An independent, unofficial Android companion app compatible with Edifier WH950NB headphones.

## Included

- ANC / Ambient / Wind / Off and supported level controls
- Codec status and LDAC / AAC / SBC requests via Shizuku
- Sound modes, EQ presets, sleep timer and local diagnostics
- Connection-aware notifications and Quick Settings controls
- Bottom tabs: Controls, Sound, Settings

## Compatibility

Tested on one WH950NB with rooted Android 16 and root-mode Shizuku. Root is not needed for the main headphone controls. Supported codec requests use Shizuku with suitable privileges; other setups have not been verified.

EQ presets may not work while Spatial mode is active. Switch to Music mode before changing EQ.

## Download and installation

Download the signed APK from the release assets:

[Download WH950NB Companion Beta 1](https://github.com/Riku-lgtm43/WH950NB-Companion/releases/download/v0.3.21-beta.1/WH950NB-Companion-v0_3_21-beta1.apk)

Install the APK, connect your WH950NB headphones through Android Bluetooth settings, and grant the required permissions. For supported advanced codec requests, start Shizuku with suitable privileges and authorize the app. Root-mode Shizuku was used in the verified setup; other configurations have not been verified.
