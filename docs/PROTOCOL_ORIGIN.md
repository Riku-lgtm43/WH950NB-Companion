# Bluetooth protocol research origin

The developer confirms independently researching Bluetooth command bytes using **Android Bluetooth HCI logs captured while operating personally owned Edifier WH950NB headphones**. Commands and responses were identified through observation and testing, then used in an earlier Tasker control project before being implemented in the Java app. The developer confirms that no Edifier application source code or firmware source code was copied.

The original HCI capture files have **not** been independently reviewed. This statement does not establish the origin or terms of every software component involved in generating the traffic, nor does it grant rights over manufacturer source code, firmware or confidential information.

The distributed source archive is not intended to include raw HCI captures, manufacturer applications, firmware or private credentials.

## Research records (keep private)

Retain original captures and dated notes recording the tested actions and observed responses. HCI logs can contain Bluetooth addresses, device identifiers and unrelated traffic. **Do not upload raw captures or unredacted examples** to source commits, issues or releases.

Only share excerpts that you have the right to disclose, after removing personal information and unrelated traffic. The protocol may vary across headphone firmware revisions.
